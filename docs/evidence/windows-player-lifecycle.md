# Windows process-lifecycle gate — 2026-10-28

/goal: stop stale presence on player exit and retain quiet sessions while the corresponding player lifetime is still observable.

/steps: production desktop adds a consent-controlled OS activity reader to the log provider. Fixed, noninteractive, hidden Windows PowerShell invokes Get-Process for RobloxPlayerBeta in its own desktop session and reads only start times. No command lines, modules, game memory, cookies, account data, elevation or persistent helper service. Query timeout 1500ms, output 16KiB maximum, <=4 results; success/error cached for five seconds. No query runs before opt-in. Policy/access/timeout/format errors clear current evidence and surface a generic reason; no fallback to assumed activity.

With exactly one player process, candidate file/event evidence must postdate that process start. Quiet logs no longer expire solely for age when a single running lifetime supports them. Exit clears evidence on the next uncached query (normally <=5s plus query/poll latency), restarting cannot reuse a preceding process's join, and multiple players or multiple eligible logs remain ambiguous. Filename suffixes are not assumed to be PIDs. Metadata is not a cryptographic association between a particular log and process, nor Roblox membership/account proof. Without an injected activity reader, standalone development fixtures retain the original 120s freshness behavior.

New cases cover quiet sessions, exit, new process with older/touched logs, multiple players, denied query, recovery, cached failure/copy behavior and disabling while a query is pending. Native Electron still exercises generated log/session/overlay fixtures; it does not fake process metadata as real Roblox proof.

A separate native metadata-only probe saw one player process. No local settings or game state changed; no network publication, raw logs or raw identifiers captured. This proves query execution and conservative rejection on this host, not successful real session detection. Actual join/teleport/exit acceptance remains unverified.
