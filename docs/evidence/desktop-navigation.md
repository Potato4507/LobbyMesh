# Desktop workspace and widget controls — 2026-10-28

/goal: make the implemented desktop flows usable as one coherent application, preserving state across navigation.

/steps: persistent sidebar with Overview, Conversations, Preferences and Overlay views; selected-page semantics, explicit view headings and keyboard focus on navigation. Global network/session/microphone status stays visible, with offline/uncertain states preserved. Inactive views are hidden rather than remounted, retaining drafts, history selection and unsaved preferences. Unsaved preference indicator remains visible in navigation; overlay changes explain why they are disabled while preference edits are pending. Layout adapts to the 720px supported minimum without horizontal overflow.

Overlay settings now have explicit accessible move-up/down controls and show selected widgets in their saved order. Bounds/visibility validation stays in the existing main-process settings contract. Compact overlay chat reuses the same permission, text validation, ACK and retention behavior with less repeated explanatory copy; the full desktop retains privacy details. No new privilege, provider claim, audio capture or grant-contact action.

/proof: Windows Node 24.22.1 / pnpm 11.25.0 / Electron 45.1.0. Full suite 93/93, typecheck, lint (98 files), build and native Electron smoke passed.
